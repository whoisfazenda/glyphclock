# Glyph Clock

Часы для Nothing Phone (3a) / (3a) Pro в стиле классического Nothing: будильник, мировое время, таймер, секундомер. Будильник и таймер подсвечивают Glyph по записи из мелодии, созданной в Glyph Composer (`.ogg`, тег `AUTHOR`).

## Возможности

- **Будильники** с круглым циферблатом, который следует системной настройке 12/24 часа; редактор открывается снизу листом (время, дни, название, мелодия, вибрация; остальное раскрывается)
- **Пропуск ближайшего раза** для повторяющихся будильников, с возможностью вернуть
- **Мировое время**, **таймеры** (несколько сразу, клавиатура как в номеронабирателе) и **секундомер** с кругами
- **Подсветка Glyph** вместе со звуком; предпросмотр показывает кольцо камеры и три полоски глифов
- **Ночной режим**: глифы горят тусклее в выбранные часы
- Мелодия выбирается в системном списке (Nothing Signals, Glyph-составитель, Мои звуки); мелодии по умолчанию для будильника и таймера
- Громкость будильника, плавное нарастание громкости (5–120 с), сдвиг света относительно звука
- Плитка в быстрых настройках со следующим будильником
- Интерфейс на русском и английском, переключается в настройках

## Установка

Скачайте `GlyphClock.apk` из [последнего релиза](../../releases/latest) и откройте на телефоне. Нужен Android 14 или новее. Сборка подписана отладочным ключом.

## О Glyph

- Включите **Glyph-интерфейс** в настройках телефона.
- На Nothing OS старше Android 16 один раз по USB выполните: `adb shell settings put global nt_glyph_interface_debug_enable 1` (действует 48 часов).
- Комплект Glyph зажигает светодиоды только приложению, которое сейчас на экране, поэтому приложению нужно разрешение «Поверх других приложений», чтобы экран сработавшего будильника открывался сам.
- Встроенные звуки Nothing OS (Nothing Signals / Machines) играют как обычно, но их свет хранит система, поэтому подсветки Glyph у них здесь нет. Используйте композиции из Glyph Composer.

## Сборка

```
gradlew.bat assembleRelease
```

APK лежит в `app/build/outputs/apk/release/app-release.apk`. В `gradle.properties` прописаны пути к JDK и кэшу Gradle конкретной машины (`D:/jdk-17`, `D:/.gradle`): поправьте под себя.
